# Vazirmatn font

This app bundles **Vazirmatn** (Regular 400, Bold 700) so Persian text and
digits work with no network access.

- Designer: Saber Rastikerdar
- Project: <https://github.com/rastikerdar/vazirmatn>
- License: SIL Open Font License 1.1 — the full text is in `OFL-1.1.txt`
- Files: `Vazirmatn-Regular.ttf`, `Vazirmatn-Bold.ttf`

The files are unmodified copies of the official release. The OFL allows
bundling and redistribution with this application; the font itself may not be
sold on its own.
